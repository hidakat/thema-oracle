# Thema Oracle / Themaコード提案

日本語の書誌情報から、国際的な書籍主題分類「Thema」の候補を提案する意思決定支援ツールです。中心主題と候補の根拠を確認し、出版社・編集者等が最終判断するために使います。

## 利用する版を選ぶ

| 版 | 用途 | 状態・案内 |
| --- | --- | --- |
| デスクトップアプリ版プラグイン | JPROのWeb登録画面から書誌を取得し推論。人間による明示承認後の転記までを支援 | [機能・動作条件・導入案内](desktop.md)。公開審査の提出準備中 |
| カスタムGPT | 書誌を渡して候補を対話的に検討 | [従来の画像付き案内](custom-gpt.md) |
| Web版プラグイン | 添付書誌から人間向けの候補・根拠を提示 | 整備中。クラウドブラウザによるJPRO操作は対象外 |

カスタムGPTの案内にあるExcel整形や操作手順は、その版の従来の案内です。デスクトップ版の動作条件・手順とは区別してください。

## プロジェクトについて

本リポジトリは、Thema Oracleの公開案内とサポート情報を置く場所です。公開者は **日高崇（JPO特別委員）**、管理アカウントは [hidakat](https://github.com/hidakat) です。肩書の表示はJPOによる公式提供・承認を意味しません。

本プロジェクトはEDItEUR、JPO、OpenAIの公式製品・公式見解を示すものではありません。提案には誤りがあり得ます。最終的なコードの採否と登録は、権限のある利用者が判断してください。
