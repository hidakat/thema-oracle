# Thema Oracle / Themaコード提案

日本語の書誌情報から、国際的な書籍主題分類「Thema」の候補を提案する意思決定支援ツールです。中心主題と候補の根拠を確認し、出版社・編集者等が最終判断するために使います。

## 利用する版を選ぶ

| 版 | 用途 | 状態・案内 |
| --- | --- | --- |
| アプリ用プラグイン | ローカルPythonで書誌読取・コード検査。ブラウザ操作が利用可能ならJPRO取得・承認後転記も支援 | [ZIPの選択と導入手順](plugin-install.md)。試用版 |
| カスタムGPT | 書誌を渡して候補を対話的に検討 | [従来の画像付き案内](custom-gpt.md) |
| Web用プラグイン | 手動取得したXLSXを読取サービスへ渡し、候補・根拠を提示 | [ZIPの選択と導入手順](plugin-install.md)。試用版 |

カスタムGPTの案内にあるExcel整形や操作手順は、その版の従来の案内です。デスクトップ版の動作条件・手順とは区別してください。
